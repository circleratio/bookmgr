# 概要
- 蔵書管理のためのウェブアプリケーション。
- Ginのサーバーサイドレンダリングにより画面も提供する。

# 管理する情報
- 下記の情報をAPIを通じてCRUDできる。
  - 書名
  - 著者
  - 評価(☆1から☆5まで)
  - メモ(自由記入)
  - ISBN
  - 出版社
  - 出版日

# 一覧・検索
- 書名・著者のフリーワード検索ができる。

# ISBNによる書誌情報取得
- 新しい本を登録する際、ISBNを入力すると Google Books API を参照して書誌情報(書名・著者・出版社・出版日等)を取得し、他の入力項目に反映できる。

# 認証
- APIキーによる簡易認証を行う。

# 技術スタック
- go / Gin Web Framework
- sqlite3
